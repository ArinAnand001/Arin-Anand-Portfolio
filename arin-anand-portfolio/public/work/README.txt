Work samples for the Skills & Services section go here.

Make one folder per skill, named after the skill's id in src/data/services.ts, for example:

  public/work/logo-brand-identity/cafe-logo.webp
  public/work/video/brand-reel.mp4

Then list each file in that skill's `samples` array in src/data/services.ts.
Images: WebP or JPG, about 1600px on the long side, under ~400 KB.
Videos: MP4 (H.264), with a poster image.
